# 智能客服系统前端全功能重构 Trellis 设计规范与实施方案

- **项目名称**：企业无人自助设备智能客服与知识治理系统（前端全功能重构）
- **技术栈**：
  - **客户端 (C端)**：`projects/customer-service-client` (Vite 6 + React 18 + TS + Vanilla CSS 变量，交付 Web SPA 与 `embed.js` Widget)
  - **管理端 (B端)**：`projects/app/src/pages/customer-service/` (Next.js + React 18 + TS + ChakraUI + Zustand)
- **当前阶段**：阶段 1 - 需求与架构规格制定（前端专攻，后端暂缓）

---

## 🎯 一、 核心目标与量化指标

1. **业务功能 100% 对齐需求规范**：
   - 彻底解决当前前端“仅有基础输入框与简单表格”的简陋现状，全面落地《智能客服 RAG 知识库系统二次开发需求与实施文档》中规定的**三级受众体系、设备故障诊断引导树、4 大结构化知识录入模板、知识 Diff 审核试问台、产品拓扑树看板与 Badcase 运营聚类**。
2. **极致用户体验与专业质感**：
   - **客户端 (C端)**：打造高品质无人设备（拍照机/售货机）专属智能服务空间，提供交互式排查清单、强视觉安全阻断警告、智能工单摘要一键复制。
   - **管理端 (B端)**：重构 2500 行巨型单体 `console.tsx` 为清晰的高内聚模块化子视图，提供专业高效的知识生产与审核流转工作台。
3. **极致性能与轻量化约束**：
   - C 端主应用 Bundle Gzip 体积保持在 **< 70 KB**，首屏渲染 **< 300ms**；
   - C 端 Widget SDK (`embed.js`) 严格采用 **Shadow DOM 样式硬隔离**，零污染宿主网站；
   - B 端控制台各子模块实现按需懒加载，杜绝无意义重渲染。

## 📦 三、 前端功能矩阵与重构设计

### 3.1 客户端 (C端 - `projects/customer-service-client`)

```
┌────────────────────────────────────────────────────────────────────────┐
│                         客户端页面布局与交互流                         │
├────────────────────────────────────────────────────────────────────────┤
│ [Top Header] 品牌 Logo | 在线状态 | 身份切换(客户/运营/售后) | 历史抽屉│
├───────────────────┬────────────────────────────────────────────────────┤
│ [设备场景化诊断树] │ [智能多轮对话流]                                   │
│ • 拍照机专区:      │  - 欢迎语与推荐问题胶囊                            │
│   - 卡纸/卡相片   │  - 用户提问气泡                                    │
│   - 触屏无反应    │  - 助手回复(流式 Markdown / 代码块复制)            │
│   - 闪光灯故障    │  - ⚡ 交互式步骤排查清单 (Checklist 卡片)          │
│ • 售货机专区:      │  - ⚠️ 强安全警告卡片 (拆机/高压电醒目红框)         │
│   - 扣费未出货    │  - 📚 引用知识卡片 (展开查看命中分与摘要)          │
│   - 货道卡货      │  - 👨‍💼 智能转人工卡片 (一键复制工单摘要 / 呼叫联系)│
│ • 错误码速查小工具 │  - 点赞 / 点踩 / 问题未解决深度反馈                │
├───────────────────┴────────────────────────────────────────────────────┤
│ [Bottom Input] 自适应输入框 | 快捷发送 | 停止生成 | 语音/截图预留     │
└────────────────────────────────────────────────────────────────────────┘
```

#### 核心新增交互组件：
1. **`AudienceSwitcher.tsx` (三级受众身份切换器)**：
   - 支持切换「普通客户 (public)」、「设备运营/经销商 (dealer)」、「内部售后技术 (internal)」；
   - 切换时提示当前权限可见范围（例如普通客户提示“仅显示安全操作指南”，内部售后提示“已解锁错误码与工程排查”）。
2. **`TroubleshootCard.tsx` (交互式排查步骤清单)**：
   - 将故障排查回答解析为交互式 Checkbox 步骤清单（用户勾选第 1 步完成 ➔ 自动亮起第 2 步 ➔ 均失败时自动弹出转人工卡片）。
3. **`SafetyAlertCard.tsx` (强视觉安全警告卡片)**：
   - 检测到高压电、拆机、制冷剂等危险关键词时，呈现带闪烁呼吸灯的醒目危险警示框，阻断普通用户自行拆机。
4. **`HumanHandoffModal.tsx` (智能转人工与工单摘要)**：
   - 触发转人工时，除展示电话外，自动一键生成**【设备型号 + 故障现象 + 已执行排查步骤 + 对话时间】**结构化工单文本，支持一键复制到微信/工单系统。
5. **`SessionDrawer.tsx` (会话历史管理抽屉)**：
   - 侧边栏展示历史会话列表，支持新建会话、切换历史会话、一键导出对话长图/Markdown、清空缓存。

### 3.2 管理运营控制台 (B端 - `projects/app/src/pages/customer-service/`)

将原有 2500 行的 `console.tsx` 拆解为 6 个高内聚子模块工作台：

```
projects/app/src/pageComponents/customerService/
├── OverviewWorkspace/       # 工作台总览（实时数据大屏、待办审批、异常告警）
├── KnowledgeStudio/        # 知识生产中心（4大结构化录入模板、批量导入）
│   ├── ProductMasterForm.tsx   # 产品主档录入模板
│   ├── ManualForm.tsx          # 操作说明录入模板
│   ├── FaqBatchEditor.tsx      # FAQ 批量导入与结构化编辑器
│   └── FaultCardForm.tsx       # 售后故障卡录入模板
├── ReviewStudio/           # 知识审核工作台（Diff 高亮对比、在线试问预览）
├── ProductStudio/          # 产品层级看板（大类/系列/型号/版本四级拓扑树）
├── OperationsStudio/       # 对话运营与 Badcase 聚类（趋势图、无答案聚类、一键转草稿）
└── SettingsStudio/         # 成员角色分配与三权分立管理
```

#### 核心新增工作台功能：
1. **4 大专业结构化知识录入表单**：
   - **产品主档模板**：录入额定功率、尺寸重量、网络供电、耗材规格、选配功能、保修期限等标准化表单，一键生成规范 Markdown；
   - **操作说明模板**：录入操作前提、步骤 1/2/3 列表、完成标志、注意事项、常见失败原因与转人工条件；
   - **FAQ 批量导入与编辑器**：支持 Excel/CSV 拖拽批量解析，录入标准问、相似问 Tags 列表、简短回答与详细补充；
   - **售后故障卡模板**：录入故障现象、错误代码、适用软硬件版本、排查步骤树、安全危险级别（普通/警告/危险）、转人工判定规则。
2. **`ReviewStudio` 知识 Diff 审核台**：
   - **新旧版本双栏 Diff 高亮**：红色删除、绿色新增；
   - **影响面预估**：展示修改该知识将影响哪些产品型号与客服项目；
   - **在线试问沙盒**：在审核页面直接输入问题，实时模拟 DeepSeek + RAG 检索该条知识的效果；
   - **审核流转**：支持选择预设驳回理由（“参数不准确”、“缺少安全警告”、“格式不符”）并附带修改批注。
3. **`OperationsStudio` 对话运营与 Badcase 聚类**：
   - **数据统计卡片**：Token/费用趋势、平均响应时长、解决率（点赞率）、转人工率；
   - **转人工归因分析**：按“扣费退款争议”、“硬件损坏”、“资料不足”、“操作超时”分类展示饼图；
   - **无答案与 Badcase 聚类列表**：展示置信度低于阈值或用户点踩的问题列表；
   - **一键转知识草稿 (One-Click To Knowledge Draft)**：点击任意未解决问题，自动将问答上下文预填入知识草稿编辑器。
4. **`ProductStudio` 四级拓扑树看板**：
   - 可视化展示 `产品大类` ➔ `产品系列` ➔ `产品型号` ➔ `软硬件版本` 树形结构；
   - 支持查看每个型号绑定的知识库总数、生效版本、停用/停产状态与产品主档卡片。
